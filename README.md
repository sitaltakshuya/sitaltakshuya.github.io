# Sital Sharma — Personal AI Research Portfolio

A responsive, animated personal portfolio built with HTML, custom CSS, vanilla JavaScript, and Bootstrap 5.3. The enhanced edition features dedicated expertise cards for Data Structures & Algorithms, Large Language Models, and Deep Learning & AI, plus a faculty profile section for the School of Computer Science and Engineering, Sikkim Manipal Institute of Technology, Sikkim Manipal University. No Node.js or build step is required.

## 1. Run locally

1. Download and unzip this folder.
2. Open `index.html` in a browser.
3. Internet access is needed for Bootstrap, Google Fonts, and the optional GitHub stat widgets.

For a local development server, open this folder in VS Code and use the **Live Server** extension.

## 2. Personalize before publishing

Search and replace these placeholders across `index.html`:

- `YOUR_GITHUB_USERNAME` — your actual GitHub username.
- `YOUR_EMAIL@example.com` — the email address you want to publish.
- `YOUR_LINKEDIN_USERNAME` — your LinkedIn profile slug.

Update the project repository links so each project points to its real repository. Remove any project or technology you do not want to claim publicly. The project cards are written as project/research directions where implementation status should be confirmed.

### Optional additions

- Add a CV PDF in `assets/` and link it from the hero or contact section.
- Add a profile photo in `assets/` if you prefer a portrait over the code-console illustration.
- Add actual publications with title, venue, year, DOI, and a verified paper link.
- Replace the GitHub stats widgets if an external service is unavailable.

## 3. Publish with GitHub Pages

1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets/` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment settings, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish. Your site will be at `https://YOUR_GITHUB_USERNAME.github.io/`.

If you want to publish from an ordinary repository instead, enable Pages in Settings and use the generated project-site URL.

## 4. Create a GitHub profile README too

GitHub profile README content belongs in a repository whose name exactly matches your username. The file `github-profile-README.md` is a starter template you can copy into that repository as `README.md`.

## Files

- `index.html` — page structure and content
- `style.css` — theme, layout, responsive design, animation
- `script.js` — typing effect, reveal animations, filters, scroll progress
- `github-profile-README.md` — separate GitHub profile README starter
